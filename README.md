# ミツモリノート

職人さん・小さな会社向けの、見積書・請求書を作るWebアプリです。品目と金額を入れるだけで消費税と合計を自動で計算し、そのままPDFにできます。

## 主な機能

- **見積書・請求書の作成**:取引先・件名・明細を入れると、税率ごとの消費税と合計を自動で計算します。「12,000」「¥3,000」のような入力も受け付けます
- **インボイス制度に対応した書き方**:登録番号、税率ごとの合計と消費税額(10%/8%軽減/非課税)、軽減税率の品目への「※」印
- **PDF出力**:画面のプレビューと同じレイアウトのPDFを、ブラウザで開く/ダウンロードできます(日本語フォント埋め込み)
- **見積から請求へ**:ボタン1つで、見積書の明細をそのまま写した請求書を作れます
- **状態の管理**:見積(下書き・提出済み・受注・失注)、請求(未入金・入金済み・期限切れ)
- **ホーム**:今月の請求額、未入金の合計、期限を過ぎた請求書、返事待ちの見積、受注率
- 取引先ごとの書類一覧と未入金額、消費税の端数処理(切り捨て・四捨五入・切り上げ)、番号の自動採番(年ごと)、書類のコピー、使い方ガイド、スマホ対応

## 計算のきまり(app/Services/Calculator.php)

1. 明細の金額 = 数量 × 単価(1円未満は四捨五入)
2. 消費税は**税率ごとに合計してから1回だけ**計算し、端数は設定の方法で処理する(インボイス制度のルール)
3. 浮動小数点の誤差で切り上げにならないよう、端数処理の前に小さく丸める

## 使っている技術

- Laravel 13 / PHP 8.4
- Blade + Tailwind CSS 4(JavaScript はほとんど使っていません)
- mPDF(PDF出力)、Noto Sans JP(日本語フォント・SIL Open Font License)
- SQLite(開発)/ MySQL(本番:Laravel Cloud)

## 動かし方(Laravel Herd)

```bash
bash ~/Herd/mitsumori-note-setup/setup.sh
```

http://mitsumori-note.test を開き、デモアカウントでログインできます。

- メールアドレス:`demo@example.com`
- パスワード:`password`

デモデータには、架空の工務店(取引先6社、見積書8件、請求書4件)が入っています。

### テスト

```bash
php artisan test
```

## 公開デモ版の設定

環境変数で `DEMO_MODE=true` にすると、ログイン画面にデモ用アカウントが表示され、新規登録とログイン情報の変更ができなくなります。毎日4時(日本時間)に `php artisan demo:reset` でデータが初期状態に戻ります。
